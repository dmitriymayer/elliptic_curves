Задача 1.4

Теорема Таннелла: площади и целые точки

Условие

Напишите компьютерную программу, проверяющую гипотезу Туннелла о связи конгруэнтности числа n∈N с количествами целых точек на эллипсоидах 2x2+y2+8z2=n и 2x2+y2+32z2=n.

X век → Ферма → 1983

Какие числа являются площадями?

Число n называют конгруэнтным, если это площадь прямоугольного треугольника с рациональными сторонами. Например, 6 — площадь треугольника 3, 4, 5, а 5 — треугольника 3/2, 20/3, 41/6. Вопрос, какие n конгруэнтны, встречается ещё в арабских рукописях X века[1, с. 3]. Ферма доказал методом спуска, что 1 не конгруэнтно[1, теорема 2.1, с. 3]: площадь пифагорова треугольника не бывает квадратом.

В 1983 году Дж. Таннелл[2, с. 323] свёл вопрос к подсчёту целых точек на двух эллипсоидах. Если n конгруэнтно, то A(n)=2B(n): это доказано. Обратное в общем виде следует из гипотезы Бёрча и Свиннертон-Дайера[3, с. 79–108], которая не доказана. Но для всех n<40000 вопрос решён без дополнительных предположений: для каждого такого бесквадратного n с A=2B конгруэнтность доказана прямым вычислением (Крамарц — до 2000[4, с. 337], Нода и Вада — до 10 000[5, с. 175], Немензо — до 40 000[6, с. 29]). Программа считает точки и отдельно ищет сам треугольник ; его стороны можно проверить вручную. Точные формулировки — ниже.

  1. 1Выберите n на карте или введите вручную, до 100 000.
  2. 2Страница перебирает целые точки на эллипсоидах и сравнивает A с 2B. Как именно — пошагово ниже.
  3. 3Если A=2B, проверяется, найден ли треугольник: это независимое доказательство того, что n действительно площадь.

Как программа находит точки на эллипсоидах

A(n) и B(n) — это количества троек целых чисел (x,y,z), для которых выполнено равенство. Программа находит их полным перебором. Ниже он показан целиком для выбранного n, и каждую клетку можно открыть.

1 · перебор конечен

Все слагаемые неотрицательны, поэтому {{boundIneq}}. Отсюда {{boundX}} и {{boundZ}}. Перебираем только этот прямоугольник пар (x,z).

2 · y не перебираем

Для каждой пары считаем остаток {{rFormula}}. Решение с этими x, z есть, только если r — точный квадрат: r=y2.

3 · считаем со знаками

Если y>0, это два решения: (x,y,z) и (x,−y,z). Если y=0, решение одно. Знаки x и z учтены самим перебором от −X до X.

Что именно доказано

Определение 1. Натуральное n конгруэнтно, если существуют рациональные a, b, c>0 с a2+b2=c2 и ab/2=n.
Лемма 2. Если n=mk2, то n конгруэнтно тогда и только тогда, когда конгруэнтно m. Поэтому достаточно рассматривать бесквадратные n.
Доказательство
Треугольник (a,b,c) площади m переходит в треугольник (ka,kb,kc) площади mk2, и наоборот: можно делить стороны на k.∎
Теорема 3 (Таннелл, 1983). Пусть n — бесквадратное натуральное число. Положим  для нечётного n:A(n)=#{(x,y,z)∈Z3:2x2+y2+8z2=n}, B(n)=#{2x2+y2+32z2=n};  для чётного n:A(n)=#{4x2+y2+8z2=n/2}, B(n)=#{4x2+y2+32z2=n/2}.(а) Если n конгруэнтно, то A(n)=2B(n).(б) Если A(n)=2B(n) и для кривой En​:y2=x3−n2x верна гипотеза Бёрча–Свиннертон-Дайера, то n конгруэнтно.
Доказательство
Доказательство использует модулярные формы веса 3/2 и выходит за рамки страницы. Идея: по следствию 9 на странице 1.3 конгруэнтность n равносильна бесконечности En​(Q). По теореме Коутса–Уайлса бесконечность влечёт L(En​,1)=0, а по гипотезе BSD верно и обратное. Таннелл выражает L(En​,1) через коэффициенты модулярной формы веса 3/2 (формула Вальдспургера): L(En​,1)=0⇔A(n)=2B(n). Подробно — в статье Таннелла[2, с. 323–334].∎
Теорема 3′ (Крамарц; Нода–Вада; Немензо). Для всех бесквадратных n<40000 верно: n конгруэнтно ⇔A(n)=2B(n). Иначе говоря, в этом диапазоне вывод (б) теоремы 3 верен без предположения BSD.
Доказательство
Направление ⇒ — теорема 3(а). Для обратного нужно для каждого бесквадратного n<40000 с A=2B доказать, что En​(Q) бесконечна, то есть предъявить точку бесконечного порядка (следствие 9 на странице 1.3). Это сделано компьютерным вычислением: до 2000 — у Крамарца[4, с. 337–340], до 10 000 — у Нода и Вада[5, с. 175–178], до 40 000 — у Немензо[6, с. 29–31]. Сами стороны треугольников для всех конгруэнтных n<10000 выписаны в таблице Голдберга[7].∎
Лемма 4. Если бесквадратное n≡5,6,7(mod8), то A(n)=B(n)=0, и условие A=2B выполнено.
Доказательство
Нечётное n. В 2x2+y2+8z2=n число y нечётно, поэтому y2≡1(mod8). Кроме того, 2x2≡0 или 2(mod8), а 8z2≡32z2≡0. Значит, левая часть ≡1 или 3(mod8), а n≡5 или 7 — решений нет.Чётное n≡6. Тогда n/2≡3(mod4), а 4x2+y2+8z2≡y2∈{0,1}(mod4) — решений нет.∎
Предложение 5 (корректность перебора). Пара (x,z) даёт решения уравнения ax2+y2+cz2=N тогда и только тогда, когда r=N−ax2−cz2 — точный квадрат. Таких решений два (y=±r​) при r>0 и одно при r=0. Все решения лежат в прямоугольнике ∣x∣≤N/a​, ∣z∣≤N/c​. Поэтому перебор этого прямоугольника вычисляет A и B точно.
Доказательство
Из y2≥0 и cz2≥0 следует ax2≤N, аналогично для z. Остальное очевидно.∎
Предложение 6 (поиск треугольников). Пусть (x,y)∈En​(Q), y=0. Тогда x=d⋅a2/e2, где a, e — натуральные, а d — бесквадратное целое (со знаком), делящее n.
Доказательство
Знаменатель — квадрат. Пусть x=m/q несократимо и pk ∥ q, k≥1. Тогда у x3 показатель p равен −3k, а у n2x — не меньше −k, поэтому у y2=x3−n2x он ровно −3k. Он чётен, значит, k чётно. Итак, q=e2, и (m,e)=1.Числитель. Умножая уравнение на e6, получаем m(m−ne2)(m+ne2)=(ye3)2 — квадрат целого числа. Пусть простое p входит в m в нечётной степени. Если бы p не делило n, то оно не делило бы и m±ne2 (иначе p∣ne2, а p∤e, так как (m,e)=1). Тогда показатель p в квадрате был бы нечётным — противоречие. Значит, бесквадратная часть d числа m делит n.Следствие для программы. Достаточно перебирать x=d⋅a2/e2 с d∣n и a, e≤500 (программа для надёжности берёт d∣2n). Каждый найденный треугольник проверяется точной арифметикой. Ненайденный треугольник ничего не доказывает: он может быть просто слишком большим. Так, для n=157 числители и знаменатели сторон состоят из десятков цифр.∎

problems/1.4-tunnell/solution.py 
from fractions import Fraction
from math import gcd, isqrt

def count(n, a, b, c):
    """Число целых точек на эллипсоиде a·x² + b·y² + c·z² = n."""
    total = 0
    for x in range(-isqrt(n // a), isqrt(n // a) + 1):
        for z in range(-isqrt(n // c), isqrt(n // c) + 1):
            r = n - a*x*x - c*z*z
            if r >= 0 and r % b == 0:
                y = isqrt(r // b)
                if y*y == r // b:
                    total += 1 if y == 0 else 2
    return total

def tunnell(n):
    """Критерий Таннелла для бесквадратного n."""
    if n % 2:                                    # эллипсоиды 2x² + y² + 8z², 2x² + y² + 32z²
        A, B = count(n, 2, 1, 8), count(n, 2, 1, 32)
    else:                                        # чётный случай
        A, B = count(n // 2, 4, 1, 8), count(n // 2, 4, 1, 32)
    return A == 2 * B

def squarefree(n):
    return all(n % (d*d) for d in range(2, isqrt(n) + 1))

def divisors_2n(n):
    return [d for d in range(1, 2*n + 1) if (2*n) % d == 0 and squarefree(d)]

def triangle(n, L):
    """Ищем точку x = d·a²/e² на кривой y² = x³ − n²x (d | 2n, a, e ≤ L)
    и превращаем её в прямоугольный треугольник площади n."""
    for e in range(1, L + 1):
        for a in range(1, L + 1):
            if gcd(a, e) > 1:
                continue
            for d in divisors_2n(n) + [-d for d in divisors_2n(n)]:
                v = d * (d*a*a - n*e*e) * (d*a*a + n*e*e)
                if v > 0 and isqrt(v)**2 == v:
                    x = Fraction(d*a*a, e*e)
                    y = Fraction(isqrt(v) * a, e**3)
                    return sorted(abs(s) for s in ((x*x - n*n) / y, 2*n*x / y, (x*x + n*n) / y))
    return None

N, L = 200, 60
ns = [n for n in range(1, N + 1) if squarefree(n)]
yes = [n for n in ns if tunnell(n)]
found = {n: triangle(n, L) for n in yes}
found = {n: t for n, t in found.items() if t}

for n, (a, b, c) in found.items():
    assert a*a + b*b == c*c and a*b/2 == n           # треугольник честный

print(f"бесквадратных n ≤ {N}: {len(ns)}, из них A = 2B: {len(yes)}")
print(f"треугольник найден для {len(found)}: {list(found)[:12]} …")
print(f"A = 2B, треугольник с a, e ≤ {L} не найден: {[n for n in yes if n not in found]}")
print("n = 5:", *found[5], "  n = 6:", *found[6])
