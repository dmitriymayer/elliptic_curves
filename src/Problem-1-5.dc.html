Задача 1.5

Три точки перегиба на одной прямой

Условие

С помощью доступных компьютерных средств изобразите плоскую вещественную кубику, на которой отчётливо видны три точки перегиба, лежащие на одной прямой.

1844 → наши дни

Три перегиба на одной прямой — в декартовых координатах

Точка перегиба — место, где кривая меняет направление изгиба, а касательная пересекает её, переходя с одной стороны кривой на другую. У кубической кривой таких точек немного, и их расположение подчинено строгим ограничениям: в 1844 году Гессе[1, с. 97–107] показал, что перегибы — это пересечения кривой с другой кубикой, её гессианом. Из его теории следует, что у гладкой вещественной кубики ровно три вещественных перегиба и они всегда лежат на одной прямой.

Чтобы это было видно на рисунке, кривую следует удачно расположить: в произвольных координатах один из перегибов может оказаться далеко от начала координат или на бесконечности. Ниже рассматривается семейство x3+12x+4y3=3k⋅y(x2−4), подобранное так, что перегибы находятся в точках (−2,2), (0, 0), (2,−2) при любом k=1. Обоснование приведено в разделе «Откуда берутся точки перегиба» и занимает несколько строк.

  1. 1Меняйте k: форма кривой меняется, а перегибы A, B, C остаются на месте на прямой y=−x.
  2. 2Касательные в перегибах (синие) переходят с одной стороны кривой на другую ; так проявляется касание третьего порядка.
  3. 3Щёлкните по кривой в любом месте: касательная в обычной точке снова пересекает кривую в точке Q. Если подвести точку к перегибу, Q сольётся с ней.

Откуда берутся точки перегиба

Все рассуждения ниже ведутся на обычной координатной плоскости R2: кривая — множество нулей многочлена от x и y.

Определение 1. Пусть кривая задана уравнением f(x,y)=0, а точка P на ней гладкая: ∇f(P)=(fx​,fy​)=0. Касательная в P — прямая P+td, где d =(fy​,−fx​). Точка P называется точкой перегиба, если многочлен g(t)=f (P+td) имеет в нуле корень кратности не меньше 3. Наглядно: обычная касательная касается кривой «один раз» (корень кратности 2) и остаётся по одну сторону от неё, а касательная в перегибе имеет касание более высокого порядка и переходит на другую сторону.
Лемма 2 (критерий перегиба). Гладкая точка P кривой f=0 — точка перегиба тогда и только тогда, когда в нейΦ =fxx​⋅fy2​−2fxy​⋅fx​fy​+fyy​⋅fx2​=0.
Доказательство
Разложим g(t)=f (P+td) по Тейлору. Свободный член g(0)=f(P)=0, так как P на кривой. Далее g′(0) = ∇f·d =fx​fy​−fy​fx​=0. Наконец, g′′(0)=fxx​d12​+2fxy​d1​d2​+fyy​d22​, и подстановка d1​=fy​, d2​=−fx​ даёт ровно Φ. Значит, корень t=0 имеет кратность ≥3 тогда и только тогда, когда Φ(P)=0.∎

Рассмотрим конкретную кубику, на которой это хорошо видно:

Определение 3. Для вещественного параметра k положим fk​(x,y)=x3+12x+4y3−3k⋅y(x2−4) и Ck​:fk​=0. Отметим три точки A=(−2,2), B=(0,0), C=(2,−2); все они лежат на прямой y=−x, и все лежат на Ck​ при любом k (проверяется подстановкой).
Лемма 4 (удобная запись). Положим u=x+2, v=2y, w=x−2. Тогда 2fk​=u3+v3+w3−3k⋅uvw.
Доказательство
Действительно, (x+2)3+(x−2)3=2x3+24x, (2y)3=8y3 и 3k⋅(x+2)⋅2y⋅(x−2)=6k⋅y(x2−4). Остаётся сложить.∎
Предложение 5. Пусть k=1. Тогда A, B, C — точки перегиба кривой Ck​, и они лежат на одной прямой y=−x. Касательные в них:TA​:(1+k)x+2y+2k−2=0, TB​:x+ky=0, TC​:(1+k)x+2y+2−2k=0.
Доказательство
Точка A. В обозначениях леммы 4 прямая TA​ — это v+w+ku=0 (это проверяется раскрытием скобок). На ней v+w=−ku, поэтомуv3+w3=(v+w)3−3vw(v+w)=−k3u3+3k⋅uvw,и по лемме 4 на прямой TA​ имеем 2fk​=(1−k3)u3. Прямая TA​ не вертикальна (коэффициент при y равен 2), поэтому u=x+2 — непостоянная линейная функция параметра на ней, обращающаяся в нуль ровно в точке A. Значит, ограничение fk​ на TA​ — это ненулевая (так как 1−k3=0) константа, умноженная на t3, где t — параметр, равный нулю в A. Точка A гладкая: ∇fk​(A)=(24(1+k),48)=0. Прямая, по которой fk​ имеет корень кратности ≥2, проходит в направлении, ортогональном градиенту, то есть это и есть касательная. Итак, A — точка перегиба.Точки B и C. Точно так же TB​:u+w+kv=0 и на ней 2fk​=(1−k3)v3; TC​:u+v+kw=0 и на ней 2fk​=(1−k3)w3. Градиенты ∇fk​(B)=(12,12k) и ∇fk​(C)=(24(1+k),48) ненулевые.Коллинеарность. u+v+w=2(x+y), и в каждой из точек A, B, C одна из величин u, v, w равна нулю, а две другие противоположны. Значит, все три лежат на прямой x+y=0.∎
Замечание 6 (что происходит при k=1). При k=1 кривая вырождается в прямую y=−x, и перегибы теряют смысл.
Доказательство
Классическое тождество u³ + v³ + w³ − 3uvw = (u + v + w)·½((u−v)2+(v−w)2+(w−u)2) даёт 2f₁ = 2(x + y)·½(…). Второй множитель положителен, так как u−w=4=0. Значит, f1​=0⇔x+y=0. В интерактиве видно, как при k→1 кривая приближается к прямой перегибов.∎

Предложение 5 объясняет, откуда берутся точки: они заложены в запись леммы 4. Остаётся вопрос, нет ли у Ck​ других вещественных перегибов. Программа ниже решает систему fk​=0, Φ =0 численно и находит ровно три решения. Строгое доказательство удобнее всего провести на проективной плоскости — это единственное место страницы, где без неё не обойтись.

Предложение 7 (других перегибов нет). При k=1 у кривой Ck​ нет вещественных точек перегиба, кроме A, B, C.
Доказательство
Добавим к плоскости бесконечно удалённую прямую: точке (x,y) сопоставим [u:v:w]=[x+2:2y:x−2]; бесконечно удалённые точки — те, где u=w. По лемме 4 кривая становится кубикой Гессе F=u3+v3+w3−3k⋅uvw=0. По теореме Гессе[1, с. 97–107] гладкая точка кубики — перегиб тогда и только тогда, когда в ней обращается в нуль гессиан H=det(∂2F/∂ui​∂uj​); это проективный аналог леммы 2. Прямое вычисление определителя матрицы ​6u−3kw−3kv​−3kw6v−3ku​−3kv−3ku6w​​ даётH=−54⋅(k2S−(4−k3)Π), где S=u3+v3+w3, Π=uvw.Перегибы — решения системы S−3kΠ=0, k2S−(4−k3)Π=0. Это линейная система относительно S и Π с определителем −(4−k3)+3k3=4(k3−1)=0, поэтому S=Π=0. Из Π=0 одна из координат равна нулю, скажем u=0; тогда v3=−w3, и над R это даёт единственную точку [0:1:−1]. Аналогично для v=0 и w=0. Получаем ровно три вещественных перегиба: [0:1:−1], [1:0:−1], [1:−1:0]. Ни один не бесконечно удалён (у них u=w), и при нормировке u−w=4 они дают ровно A, B, C. (Над ℂ получается 9 перегибов: v=−εw для трёх кубических корней ε из 1, и так для каждой координаты.)∎
Предложение 8 (взгляд через групповой закон). Примем перегиб B=(0,0) за ноль группового закона на Ck​: как на странице 1.3, для точек P, Q берём третью точку P∗Q прямой PQ, а P+Q — третья точка прямой через B и P∗Q (на странице 1.3 нулём служила бесконечно удалённая точка, и вторая прямая была вертикальной). Тогда противоположная точка — это центральная симметрия: −(x,y)=(−x,−y); точки P, Q, R лежат на одной прямой ⇔P+Q+R=0; перегибы — это в точности точки с 3P=0. В частности, C=−A, а коллинеарность A, B, C — это равенство A+0+(−A)=0.
Доказательство
Многочлен fk​ нечётен: fk​(−x,−y)=−fk​(x,y). Поэтому прямая через точку P и начало координат пересекает кривую в P, в B и в −P; по определению сложения −P и есть противоположная к P точка, когда ноль — перегиб (касательная в B пересекает кривую только в B). Если P, Q, R на одной прямой, то P+Q — точка, противоположная R, то есть P+Q+R=0; обратное следует из того, что третья точка прямой однозначна. Наконец, касательная в P пересекает кривую в P, P и третьей точке R, так что 2P+R=0. Перегиб — это R=P, то есть 3P=0.[2, §I.3, с. 25–27]∎

from fractions import Fraction as Q

def f(x, y, k):
    """Кубика C_k:  x³ + 12x + 4y³ − 3k·y(x² − 4) = 0."""
    return x**3 + 12*x + 4*y**3 - 3*k*y*(x*x - 4)

def restrict(P, d, k):
    """Коэффициенты c0..c3 многочлена t ↦ f(P + t·d) (кубика ⇒ степень ≤ 3)."""
    v = [f(P[0] + t*d[0], P[1] + t*d[1], k) for t in range(4)]
    d1 = [v[i+1] - v[i] for i in range(3)]
    d2 = [d1[1] - d1[0], d1[2] - d1[1]]
    c3 = Q(d2[1] - d2[0], 6); c2 = Q(d2[0], 2) - 3*c3; c1 = d1[0] - c2 - c3
    return v[0], c1, c2, c3

# три точки и прямые, которые пересекают кривую только в них (касательные)
FLEX = {
    'A': ((-2, 2), lambda k: (2, -(1 + k))),   # касательная (1+k)x + 2y + 2k − 2 = 0
    'B': ((0, 0),  lambda k: (k, -1)),         # касательная x + ky = 0
    'C': ((2, -2), lambda k: (2, -(1 + k))),   # касательная (1+k)x + 2y + 2 − 2k = 0
}
print("Ограничение f на касательную в перегибе:  f(P + t·d) = c0 + c1·t + c2·t² + c3·t³")
for k in [Q(-3), Q(-1), Q(0), Q(1, 2), Q(2)]:
    row = []
    for name, (P, d) in FLEX.items():
        c = restrict(P, d(k), k)
        assert c[:3] == (0, 0, 0) and c[3] == (4 if name != 'B' else -4) * (1 - k**3)
        row.append(f"{name}: {c[3]}·t³")
    print(f"  k = {str(k):>4}:  " + ",   ".join(row))
print("  на одной прямой y = −x:", all(P[0] + P[1] == 0 for P, _ in FLEX.values()))

# Других вещественных перегибов нет: ищем все решения системы
#   f = 0,  Φ = f_xx·f_y² − 2 f_xy·f_x·f_y + f_yy·f_x² = 0   (Φ = 0 ⇔ кривизна равна нулю)
def grad_hess(x, y, k):
    fx, fy = 3*x*x + 12 - 6*k*x*y, 12*y*y - 3*k*(x*x - 4)
    return fx, fy, 6*x - 6*k*y, -6*k*x, 24*y

def system(x, y, k):
    fx, fy, fxx, fxy, fyy = grad_hess(x, y, k)
    return f(x, y, k), fxx*fy*fy - 2*fxy*fx*fy + fyy*fx*fx

def newton(x, y, k, steps=60):
    for _ in range(steps):
        F0, G0 = system(x, y, k); h = 1e-7
        Fx, Gx = [(a - b) / h for a, b in zip(system(x + h, y, k), (F0, G0))]
        Fy, Gy = [(a - b) / h for a, b in zip(system(x, y + h, k), (F0, G0))]
        det = Fx*Gy - Fy*Gx
        if abs(det) < 1e-14: return None
        x, y = x - (F0*Gy - Fy*G0) / det, y - (Fx*G0 - F0*Gx) / det
        if abs(x) > 1e4 or abs(y) > 1e4: return None
    F0, G0 = system(x, y, k)
    return (x, y) if abs(F0) < 1e-8 and abs(G0) < 1e-6 else None

for k in [-3, -1, 0, 0.5, 2]:
    found = set()
    for i in range(-30, 31):
        for j in range(-30, 31):
            r = newton(i / 3, j / 3, k)
            if r: found.add((round(r[0], 6) + 0.0, round(r[1], 6) + 0.0))
    print(f"k = {k:>4}: вещественные перегибы", sorted(found))
