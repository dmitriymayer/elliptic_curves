Задача 1.2

Все ли пифагоровы тройки даёт формула Евклида?

Условие

Все ли пифагоровы тройки (a,b,c) имеют вид a=m2−n2, b=2mn, c=m2+n2, где m, n∈N?

Вавилон → Евклид, «Начала», книга X

Формула Евклида — это все тройки?

Эта формула известна с глубокой древности. По реконструкции Нойгебауэра и Сакса[1][2, с. 176–177] ею пользовался писец таблички Plimpton 322 (задача 1.1), а у Евклида она появляется как лемма к предложению 29 X книги «Начал»[3]. Проверка сводится к одному тождеству: (m2−n2)2+(2mn)2=(m2+n2)2.

Задача спрашивает обратное: любую ли тройку можно так получить. Ответ отрицательный; всё определяется общим множителем тройки: он должен быть квадратом или удвоенным квадратом (теорема 2 ниже). Это видно на «лестнице кратных» ниже, а произвольную тройку можно проверить в форме ниже.

  1. 1Введите катеты a и b или выберите пример. Страница проверит, что c=a2+b2​ целое.
  2. 2Программа находит общий множитель k=НОД(a,b,c) и примитивную часть тройки.
  3. 3Если k — квадрат или удвоенный квадрат, она предъявляет m, n; иначе формула эту тройку не даёт.

Белые клетки — примитивные тройки: m, n взаимно просты и разной чётности. Оранжевые «×2» получаются, когда m и n оба нечётны: формула выдаёт удвоенную примитивную тройку. Так (3, 1) даёт 8⋅6⋅10, то есть 2⋅(4⋅3⋅5). Серые — общий множитель у самих m, n. Тройку 9⋅12⋅15 не встречается ни в одной клетке (следствие 3).

Ответ и доказательство

Ответ: нет. Формула даёт не все тройки, и ниже точно описано, какие именно. Тройки сравниваем с точностью до порядка катетов: у Евклида второй катет 2mn всегда чётный, поэтому (4, 3, 5) получается как (3, 4, 5) с переставленными катетами.

Теорема 1 (классификация; сама формула восходит к Евклиду[3]). Пусть (a,b,c) — примитивная пифагорова тройка (НОД(a,b,c)=1). Тогда ровно один катет чётен. Если чётен b, то существуют единственные взаимно простые m>n>0 разной чётности с a=m2−n2, b=2mn, c=m2+n2. Обратно, при таких m, n формула даёт примитивную тройку.
Доказательство
Чётность. Если оба катета нечётны, то c2≡2(mod4), а квадраты по модулю 4 равны 0 или 1. Если оба чётны, то и c чётно, что противоречит примитивности.Существование. Пусть b чётен; тогда a, c нечётны, и u=(c+a)/2, v=(c−a)/2 — взаимно простые натуральные числа (их общий делитель делит u+v=c и u−v=a). Из b2=(c−a)(c+a) получаем (b/2)2=uv, поэтому u=m2, v=n2. Отсюда c=m2+n2, a=m2−n2, b=2mn; m, n взаимно просты, а так как c нечётно, разной чётности. Единственность: m2, n2 однозначно выражаются через a, c.Обратно. Тождество (m2−n2)2+(2mn)2=(m2+n2)2 проверяется раскрытием скобок. Если простое p делит m2±n2, то p∣2m2 и p∣2n2; p=2, так как m2+n2 нечётно, значит, p∣m и p∣n — противоречие.∎
Теорема 2. Пусть (a,b,c)=k⋅T, где T — примитивная тройка и k=НОД(a,b,c). Формула Евклида (с точностью до порядка катетов) даёт эту тройку тогда и только тогда, когда k=s2 или k=2s2 для натурального s.
Доказательство
Что даёт формула. Пусть g=НОД(m,n), m=gm′, n=gn′. Тогда тройка Евклида для (m,n) равна g2⋅E(m′,n′). Если m′, n′ разной чётности, то E(m′,n′) примитивна по теореме 1, и k=g2. Если оба нечётны, то все три числа E(m′,n′) чётны, и E(m′,n′)=2⋅E(μ, ν) с переставленными катетами, где μ =(m′+n′)/2, ν=(m′−n′)/2 взаимно просты и разной чётности. Это проверяется подстановкой: m′2−n′2=4μν, 2m′n′=2(μ2−ν2), m′2+n′2=2(μ2+ν2). Тогда k=2g2.Обратно. По теореме 1T=E(μ, ν) с точностью до порядка катетов. Если k=s2, берём m = sμ, n=sν. Если k=2s2, берём m=s(μ + ν), n=s(μ − ν): по вычислению выше это даёт 2s2⋅T.∎
Следствие 3. Тройка (9,12,15)=3⋅(3,4,5) не имеет вида (m2−n2,2mn,m2+n2) ни при каких m, n∈N и ни при каком порядке катетов: 3 не является ни квадратом, ни удвоенным квадратом. Это наименьший такой пример; следующие — 5⋅(3,4,5) и 3⋅(5,12,13).

Программа ниже проверяет теорему 2 для всех троек с гипотенузой до 1000. Связь с задачей 1.1: точка (a/c,b/c) на окружности даёт наклон t=b/(a+c)=n/m, то есть по рациональной точке однозначно восстанавливается примитивная тройка, а множитель k по точке окружности не определяется.

Код

problems/1.2-euclid/solution.py 
from math import gcd, isqrt

def euclid(m, n):
    """Тройка Евклида: (m² − n², 2mn, m² + n²)."""
    return m*m - n*n, 2*m*n, m*m + n*n

def from_euclid(a, b, c):
    """Есть ли m > n > 0 с {m² − n², 2mn} = {a, b} (порядок катетов не важен)?"""
    for x, y in ((a, b), (b, a)):
        if y % 2 == 0:
            for m in range(1, isqrt(c) + 1):
                n2 = m*m - x
                if n2 > 0 and isqrt(n2)**2 == n2 and 2*m*isqrt(n2) == y:
                    return True
    return False

def square_or_twice(k):
    """k = s² или k = 2s²?"""
    return isqrt(k)**2 == k or (k % 2 == 0 and isqrt(k // 2)**2 == k // 2)

N = 1000
triples = [(a, b, isqrt(a*a + b*b)) for a in range(1, N) for b in range(a + 1, N)
           if isqrt(a*a + b*b)**2 == a*a + b*b and isqrt(a*a + b*b) <= N]

# Теорема 2: формула даёт тройку ⇔ НОД = s² или 2s²
for a, b, c in triples:
    assert from_euclid(a, b, c) == square_or_twice(gcd(a, b))

bad = [t for t in triples if not from_euclid(*t)]
print(f"троек с c ≤ {N} (a < b): {len(triples)}; формула Евклида не даёт: {len(bad)}")
print("критерий «НОД = s² или 2s²» подтверждён для всех")
print("самые маленькие контрпримеры:", bad[:4])
