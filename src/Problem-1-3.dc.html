Задача 1.3

Конгруэнтные числа и метод секущих и касательных

Условие

Для нескольких конгруэнтных n (то есть площадей рациональных прямоугольных треугольников) найдите нетривиальные точки (с y=0) на эллиптической кривой y2=x3−n2x. Пользуясь методом секущих и касательных, размножьте эти точки.

Групповой закон: определения и теоремы

Пусть n≥1 — целое и En​:y2=x3−n2x. Многочлен x(x−n)(x+n) имеет три различных корня, поэтому кривая гладкая. Её проективное замыкание Y2Z=X3−n2XZ2 добавляет ровно одну точку O=[0:1:0], через которую проходят все вертикальные прямые. Через En​(Q) обозначим рациональные точки кривой вместе с O. Подробное изложение — у Милна[1, §I.3, с. 25–27].

Лемма 1. Если прямая с рациональными коэффициентами пересекает En​ в двух рациональных точках (с учётом кратности), то и третья точка пересечения рациональна.
Доказательство
Невертикальная прямая — это y=λx+ν с λ, ν∈Q. Через две рациональные точки проходит именно такая прямая, а касательная в рациональной точке (x1​,y1​), y1​=0, имеет наклон λ=(3x12​−n2)/(2y1​)∈Q: это следует из дифференцирования 2yy′=3x2−n2.Подстановка даёт x3−λ2x2−(2λν+n2)x−ν2=0. Это приведённый кубический многочлен с рациональными коэффициентами, и его корни — абсциссы трёх точек пересечения с учётом кратности. По теореме Виета x1​+x2​+x3​=λ2, поэтому x3​=λ2−x1​−x2​∈Q и y3​=λx3​+ν∈Q.Вертикальная прямая x=x1​ пересекает кривую в (x1​,±y1​) и в бесконечно удалённой точке O.∎
Определение 2. Для P, Q∈En​(Q) проведём прямую через P и Q (касательную, если P=Q), и пусть R — её третья точка пересечения с кривой. Положим P+Q:=−R, где −(x,y)=(x,−y) и −O=O. Иначе говоря, P+Q+R=O тогда и только тогда, когда P, Q, R лежат на одной прямой.
Предложение 3. Пусть P=(x1​,y1​), Q=(x2​,y2​) и Q=−P. Тогда P+Q=(x3​,y3​), где x3​=λ2−x1​−x2​, y3​=λ(x1​−x3​)−y1​. Здесь λ=(y2​−y1​)/(x2​−x1​) при x1​=x2​ и λ=(3x12​−n2)/(2y1​) при P=Q. Если Q=−P, то P+Q=O.
Доказательство
По лемме 1 третья точка — R=(x3​,λx3​+ν), где ν=y1​−λx1​, то есть R=(x3​,λ(x3​−x1​)+y1​). Отражая, получаем −R=(x3​,λ(x1​−x3​)−y1​). Если Q=−P, прямая вертикальна, третья точка — O, и P+Q=−O=O. В частности, точки с y=0 имеют вертикальную касательную, и для них 2P=O.∎
Теорема 4. (En​(Q),+) — абелева группа с нейтральным элементом O.
Доказательство
Замкнутость следует из леммы 1. Коммутативность: прямая через P, Q — та же, что через Q, P. Ноль: прямая через P и O вертикальна, её третья точка −P, поэтому P+O=−(−P)=P. Обратный элемент: P+(−P)=O по предложению 3.Ассоциативность — единственная трудная часть. Её доказательство вынесено в отдельный файл курса[2]; геометрическое доказательство через теорему о девяти точках есть также у Милна[1, с. 26–27].∎

Структуру группы на рациональных точках кубики заметил Пуанкаре[3][4, с. 4–5], хотя сам приём «прямая через известные точки» восходит к Диофанту: в «Арифметике» (кн. IV, задача 24) он проводит касательную к кривой y(6−y)=x3−x[4, с. 3–4]. Обозначим kP=P+⋯+P (k слагаемых). Именно эти точки строит интерактив ниже: kP=(k−1)P+P.

Теорема 5 (Морделл, 1922[5, с. 138–139][1, теорема 2.1, с. 19]). E(Q) конечно порождена: E(Q)≅Zr⊕T, где T — конечная подгруппа кручения, а r≥0 — ранг.
Предложение 6. Подгруппа кручения En​(Q) равна {O,(0,0),(n,0),(−n,0)}≅Z/2×Z/2[6, с. 1–3].
Доказательство
По предложению 3 эти четыре точки — в точности решения уравнения 2P=O, поэтому T их содержит. Для простого p∤2n редукция по модулю p вкладывает T в группу En​(Fp​)[6, с. 2–3], поэтому ∣T∣ делит #En​(Fp​).Пусть p≡3(mod4). Тогда −1 — квадратичный невычет по модулю p, а f(x)=x3−n2x нечётна: f(−x)=−f(x). Для каждой из (p−3)/2 пар {x,−x} с f(x)=0 ровно одно из чисел f(±x) — ненулевой квадрат и даёт две точки. Вместе с тремя точками с y=0 и точкой O получаем #En​(Fp​)=(p−3)+3+1=p+1.Если бы нечётное простое ℓ делило ∣T∣, то по теореме Дирихле нашлось бы простое p∤2n с p≡3(mod4) и p≡1(modℓ). Тогда p+1≡2(modℓ) не делится на ℓ — противоречие. Если бы 8∣∣T∣, то для p≡3(mod8) число p+1≡4(mod8) не делилось бы на 8. Значит, ∣T∣ делит 4, и T — ровно эти четыре точки.∎
Следствие 7. Если P∈En​(Q) и y(P)=0, то P имеет бесконечный порядок, и точки P, 2P, 3P, … попарно различны.
Доказательство
Точка P не входит в список предложения 6, значит, она не лежит в T. Если kP=lP при k>l, то (k−l)P=O, то есть P∈T.∎
III век → 1901 → 1922

Метод секущих и касательных: бесконечно много точек из одной

У Диофанта (задача IV.24 «Арифметики») новое рациональное решение получается так: через известную рациональную точку кубической кривой проводится прямая, а остаток уравнения после деления на известные корни даёт ещё один рациональный корень[4, с. 3–4]. Геометрически: прямая пересекает кубику в трёх точках с учётом кратности; если две из них рациональны, то рациональна и третья (теорема Виета). Если известна лишь одна точка, проводят касательную в ней: точка касания учитывается с кратностью два. Это и есть метод секущих и касательных.

В 1901 году Пуанкаре[3] заметил, что этот приём, дополненный отражением относительно оси x, превращает рациональные точки кривой в группу (теорема 4 выше). В 1922 году Морделл[5, с. 138–139] доказал, что все рациональные точки получаются так из конечного набора. В интерактиве ниже строятся точки P, 2P, 3P, … именно этим методом, по одному шагу.

  1. 1Выберите n. Стартовая точка P найдена перебором небольших x.
  2. 2Каждое построение kP=(k−1)P+P разбито на четыре шага: точки → прямая (для 2P — касательная) → третья точка R → отражение.
  3. 3Каждая новая точка — новый прямоугольный треугольник площади n; справа он проверяется точной арифметикой.
  4. 4Сложение здесь совпадает с групповой операцией ⊕ из определения 2: третья точка R=(k−1)P ∗ P, затем отражение.
  5. 5График можно двигать мышью и приближать кнопками; «Показать точки» подгоняет окно под текущее построение.

Точки и треугольники

Предложение 8. (см. [7, теорема 4.1, с. 5]) (а) Если P=(x,y)∈En​(Q), y=0, то числа a=∣x2−n2∣/∣y∣, b=∣2nx∣/∣y∣, c=(x2+n2)/∣y∣ — стороны прямоугольного треугольника площади n.(б) Обратно, если a2+b2=c2 и ab/2=n (стороны рациональны), то (c2/4,c(b2−a2)/8)∈En​(Q), и вторая координата не равна 0.(в) В пункте (а) один и тот же треугольник получается не более чем из восьми точек.
Доказательство
(а) x=0 и x2=n2, иначе y=0, поэтому a, b>0. Далее a2+b2=((x2−n2)2+4n2x2)/y2=(x2+n2)2/y2=c2 и ab/2=n∣x(x2−n2)∣/y2=n, потому что x(x2−n2)=y2.(б) Пусть x=c2/4. Тогда x∓n=(a2+b2∓2ab)/4=(a∓b)2/4, и x(x−n)(x+n)=(c(a2−b2)/8)2. Равенство a=b невозможно: тогда c=a2​∈/Q.(в) Из формул (а) получаем {c+a,c−a}={2x2/∣y∣,2n2/∣y∣}, поэтому (c+a)/b∈{∣x∣/n,n/∣x∣}. Для ∣x∣ остаётся два значения, для знака x — два, и y по x определяется с точностью до знака.∎
Следствие 9. n конгруэнтно ⇔ на En​ есть рациональная точка с y=0⇔ ранг En​(Q) положителен. В этом случае прямоугольных треугольников площади n бесконечно много[7, замечание 4.10, с. 12].
Доказательство
Первая эквивалентность — предложение 8, вторая — предложение 6 вместе с теоремой 5. Бесконечность следует из следствия 7 и пункта (в) предложения 8: бесконечно много различных точек kP дают бесконечно много треугольников.∎

Например, треугольник 3, 4, 5 даёт по (б) точку (25/4, 35/8) на E6​, а это −2P для P=(−3,9): проверьте в интерактиве.

from fractions import Fraction as Q

def add(P, R, n):
    """Сумма точек на y² = x³ − n²x методом секущих и касательных."""
    if P is None: return R
    if R is None: return P
    (x1, y1), (x2, y2) = P, R
    if x1 == x2 and y1 == -y2:
        return None                               # точка на бесконечности
    if P == R:
        lam = (3*x1*x1 - n*n) / (2*y1)            # касательная
    else:
        lam = (y2 - y1) / (x2 - x1)               # секущая
    x3 = lam*lam - x1 - x2                        # третья точка пересечения…
    y3 = lam*(x1 - x3) - y1                       # …отражённая относительно оси x
    return (x3, y3)

def triangle(P, n):
    """Точка (x, y), y ≠ 0  →  прямоугольный треугольник площади n."""
    x, y = P
    return abs((x*x - n*n) / y), abs(2*n*x / y), abs((x*x + n*n) / y)

def digits(q):
    return max(len(str(abs(q.numerator))), len(str(q.denominator)))

# Стартовые точки найдены перебором маленьких целых x
start = {5: (Q(-4), Q(6)), 6: (Q(-3), Q(9)), 7: (Q(25), Q(120))}

for n, P in start.items():
    assert P[1]**2 == P[0]**3 - n*n*P[0]
    print(f"n = {n}, P = ({P[0]}, {P[1]})")
    R = P
    for k in range(1, 9):
        a, b, c = triangle(R, n)
        assert a*a + b*b == c*c and a*b/2 == n          # честный треугольник
        print(f"  {k}P: цифр в x — {digits(R[0]):>4};  треугольник с гипотенузой {c}"
              if k < 3 else f"  {k}P: цифр в x — {digits(R[0]):>4}")
        R = add(R, P, n)
